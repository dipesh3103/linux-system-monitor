
🐧 Linux System Monitor Dashboard
A web-based dashboard to monitor Linux system resources in real time.

This project is built using Ubuntu WSL, Python, Flask, psutil, HTML, CSS, and JavaScript. It helps users understand Linux system information and resource utilization through a simple web interface.
🚀 Features
- Displays system hostname.
- Shows operating system information.
- Displays system uptime.
- Monitors CPU usage.
- Monitors RAM usage.
- Monitors disk usage.
- Automatically refreshes system statistics.
- Provides a responsive dark-themed dashboard.
🛠️ Technologies Used
- Linux (Ubuntu WSL)
- Python
- Flask
- psutil
- HTML5
- CSS3
- JavaScript
- Git and GitHub
📋 Prerequisites
- Ubuntu on WSL
- Python 3
- pip
- Git
⚙️ Installation and Setup
1. Clone the Repository
git clone https://github.com/dipesh3103/linux-system-monitor.git
cd linux-system-monitor
2. Create a Virtual Environment
python3 -m venv venv
3. Activate the Virtual Environment
source venv/bin/activate
4. Install Dependencies
pip install -r requirements.txt
5. Run the Application
python3 app.py
6. Open the Dashboard
Open your browser and visit:

http://localhost:5000
📊 System Information Monitored
Resource	Description
CPU	Processor utilization
Memory	RAM usage
Disk	Disk space utilization
Hostname	System hostname
Operating System	Linux system information
Uptime	Time since the system started
