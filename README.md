# 🐧 Linux System Monitor Dashboard

A simple web dashboard to monitor Linux system resources.

## 🚀 Features
- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- System hostname
- Operating system information
- System uptime
- Automatic updates

## 🛠️ Technologies Used
- Ubuntu WSL
- Python
- Flask
- psutil
- HTML, CSS, JavaScript
- Git and GitHub
